## ✨ About Me

I'm a Melbourne-based full-stack developer who just graduated with a **Bachelor of Computer Science** from Swinburne University (High Distinctions in web dev and software engineering 🎓).

I build two main types of things:

1. **Customer-facing websites** — responsive, mobile-first sites for small businesses, optimised for SEO
2. **Internal tools** — warehouse order management, barcode scanning, shipping labels, shipment planning

I don't overthink my tech choices. I pick the right tool for the job:
- **Next.js + Tailwind** for web apps that need to look good
- **Flask** for internal tools and quick backends
- **Laravel + PHP** for full-stack apps and uni projects
- **MySQL** for databases (my jam 🍝)
- Getting comfortable with **AWS** ☁️

When I'm not coding, I'm out shooting photography or solving puzzles. Coffee is non-negotiable. ☕
